## Project in one paragraph
ShotCaller is a polished, official-looking Electron desktop app: a cross-game achievement hub (Steam first, real-time unlock popups, XP, profiles, friends) plus per-game overlay modules. The first game module is Skillshot City (free-to-play roguelite battle royale, Steam app 308600, SkillshotCity.exe). Public MIT repo https://github.com/Battlebornplayz/ShotCaller, installed from GitHub Releases, with a launcher splash that offers updates. Stack: Electron 45 + TypeScript + React 19 + Vite 8 (electron-vite), electron-builder, electron-updater, uiohook-napi; Supabase from this phase.

## Decisions & constraints to respect
- No memory reading / injection, ever. Steam Web API key never ships in the app: all Steam API calls go through the Edge Function proxy.
- Privacy: cloud gets synced profile data only; crash reports opt-in; no usage analytics.
- Renderer talks to main only through `window.shotcaller` (contextIsolation + sandbox on). Add IPC names to `shared/ipc.ts`, types to `shared/types.ts`, settings fields to `electron/settings.ts` (keep `sanitize()` strict).
- Look: Mobalytics-inspired navy (#0F1023 / #1A1C3A / #090A18), #4F8CFF accent, lavender #8F93C9; reuse classes in `src/styles/global.css` (card, pill, btn, toggle, row, section-label).
- Releasing: push an annotated tag (`git tag -a vX.Y.Z -m "notes"`); CI sets the version. Tag message = launcher patch notes.
- The user wants to save usage: they're happy to do manual GUI testing themselves, so give them short checklists instead of driving the desktop at length.

## Loose ends / known issues
- Phase 3 is not released yet (last tag v0.0.2). Before tagging, run `npm run dist` once and check the installed build: the uiohook-napi native module loads (Settings shows no "Alt-key listener couldn't start" warning), the tray icon and window icon appear, and "Start with your computer" registers. The first release after v0.0.2 also ships the silent-update fix; test one update from it afterwards.
- Not tested yet (user said they'd check): second-monitor mode, hotkey-popup mode, tray menu and close-to-tray, the "Add a game" file picker, onGameLaunch = "open ShotCaller".
- Skillshot City (borderless fullscreen) minimizes when another window takes focus, so the "open ShotCaller on game launch" option will minimize the game. The default is "show the overlay" only.
- The default top-right overlay position covers Skillshot City's QUIT button; users can drag it (Alt + drag). Consider a different default in Phase 8 when the real panels exist.
- Existing settings files keep whatever hotkeys they had; only new installs get Alt+N for Next round.
- Linux: AppImage, `/proc` detection, Proton argv matching and the uiohook X11 hook are all untested on a real Linux machine.
- Unsigned builds → SmartScreen warning (documented in README). Renderer bundle ~640 kB in one chunk (fine for now).
